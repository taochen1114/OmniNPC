# 前端套件安裝方式
1. 此專案的前端，是使用 yarn 作為套件管理工具，**使用前要先全域安裝 `yarn`**
   - 安裝方式可參考
     - [yarn 官網 - mac 安裝](https://classic.yarnpkg.com/lang/en/docs/install/#mac-stable)
     - [yarn 官網 - Windows 安裝](https://classic.yarnpkg.com/lang/en/docs/install/#windows-stable)
   - 專案創建時
     - yarn 版本是使用 1.22.22
     - React 版本是使用 18.2.0
2. 路徑切換到 root/frontend
3. 使用 `yarn` 或 `yarn install` 安裝套件 (兩個指令等價)


# 前端啟動方式
1. 路徑切換到 root/frontend
2. 透過 `yarn dev` 啟用前端
